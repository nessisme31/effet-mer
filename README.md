# Effet Mer — Application de gestion de locations nautiques

Application développée pour la base nautique **Effet Mer** (WAVELY MAROC SARLAU).

## Stack technique
- React + TypeScript + Vite
- Tailwind CSS
- Supabase (base de données + authentification)
- Vercel (hébergement)

## Installation

1. Cloner le dépôt
2. Copier `.env.example` en `.env` et renseigner les clés Supabase
3. Lancer `npm install`
4. Lancer `npm run dev`

## Variables d'environnement requises

```
VITE_SUPABASE_URL=https://xxxxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGc...
```
